## 8. 会话补充 · 2026-08-24（编辑器运行时崩溃修复）

### 8.1 问题
编辑器启动时崩溃：`React.createElement: type is invalid ... but got: undefined`，`Check the render method of ActionMenu`。

### 8.2 根因
mistwarp 分支把 `src/components/action-menu/action-menu.jsx` 的 tooltip 从 react-tooltip **v3 迁移到 v5** API，但 Bilup 项目依赖仍为 **react-tooltip@3.8.0**（合并时未同步升级依赖）：
- v3：`import ReactTooltip from 'react-tooltip'` + `data-tip`/`data-for` + `<ReactTooltip/>`
- v5（合并后）：`import {Tooltip} from 'react-tooltip'` + `data-tooltip-content`/`data-tooltip-id` + `<Tooltip/>`

v3.8.0 只导出 default，无 `Tooltip` named export → `Tooltip` 为 `undefined` → 渲染崩溃。全仓库仅 `action-menu.jsx` 用了 v5 API，其余文件（`coming-soon`/`project-input`）均为 v3 用法。

### 8.3 修复（`src/components/action-menu/action-menu.jsx`）
保留 mistwarp 的功能增强（键盘导航、`clickDelayer` 延迟关闭、三 tooltip id 区分），仅将 tooltip 渲染降级为 v3 API：
- `import {Tooltip}` → `import ReactTooltip from 'react-tooltip'`
- `data-tooltip-id`/`data-tooltip-content` → `data-for`/`data-tip`
- 3 个 `<Tooltip id/place/className/ref>` → 3 个 `<ReactTooltip id/place/className/effect="solid">`
- 移除 `tooltipRefs`（v3 无 ref 控制 API）；`hideTooltips()` 降为 no-op（v3 tooltip 随菜单收起自动隐藏）

验证：babel 语法通过、eslint 0 错误。`title` 均为 `intl.formatMessage()` 返回的字符串，`data-tip` 兼容 v3。
